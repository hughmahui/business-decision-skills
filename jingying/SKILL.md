# 经营

一套从 11 位经营管理思想家的**公开权威素材**中提炼出来的**可操作经营决策操作系统**。

核心主张：**经营能力 = 把"生意里看不清的东西"处理成"可以下的决心"的能力。**

**与「决策」技能的分工**：`决策` 处理的是**政治/战略级的重大判断**（对抗工况与建设工况），素材来自毛选、邓选原文；`经营` 处理的是**企业与业务级的经营判断**，素材来自现代管理学。两者可叠加——用「决策」定大势与中心任务，用「经营」拆解生意与组织。

## 二、四条经营铁律

**铁律一：先定义"我们为谁创造什么"，再谈怎么赚钱**
德鲁克：企业的目的是创造顾客，利润是结果不是目的。波特：行业盈利性由五力结构决定，不由你多努力决定。祖克：九成实现十年持续盈利增长的公司靠的是聚焦核心。
→ 经营决策第一步是确认顾客与结构，不是确认利润。

**铁律二：没有取舍就没有战略**
波特："Operational effectiveness is not strategy." 祖克：多元化的失败占企业灾难的 75%。彼得斯：不离本行，警惕"综效"这个词。
→ 能说出"我放弃了什么"才算有战略；什么都想要是愿望。

**铁律三：问题多半出在结构和系统，不单独出在人**
圣吉："是系统的囚徒，还是我们自己思想的囚徒？" 哈默尔："Bureaucracy is soul crushing." 明茨伯格：先观察实际发生的事。
→ 先改结构/流程/激励，再谈人的态度和能力。

**铁律四：变革是过程不是宣布，且必须可传承**
科特：八步缺一不可，70% 变革失败可归因到某一步被跳过。迪奇：赢的公司"grow leadership at every level"。哈默尔：概念创新先于技术创新。
→ 变革要设计成可教、可复制、可传承的循环。

## 三、八步经营决策法（主流程，照做即可）

**第 1 步｜定义真问题：生意问题还是管理问题**
生意问题→德鲁克/波特/祖克（顾客、结构、核心业务）；管理问题→圣吉/科特/哈默尔（系统、变革、组织）。
输出物：一句话问题定义 + 归类

**第 2 步｜回到现场：拿一手事实**
明茨伯格：观察实际发生的事，不是岗位说明书。彼得斯：MBWA 亲自到现场。德鲁克：由顾客定义事业。
输出物：一线观察 ≥3 条，含顾客原话

**第 3 步｜做结构分析**
波特画五力标"最紧的约束"；圣吉画因果回路标正负反馈与延迟；祖克界定核心算利润集中度。
输出物：一张结构图 + 一个"最紧约束"结论

**第 4 步｜立判据：什么算对，什么算错（先立判据再下决心）**
德鲁克：验证在于成果。波特：取舍是否真实存在。祖克：核心地位强不强／模式可不可复制／客户洞察够不够。曾仕强：合不合理（不只是合不合法）。
输出物：3—5 条可检验判据，含量化阈值

**第 5 步｜收敛到一个中心**
德鲁克：一次只做一件最重要的事。祖克：按序推进相邻动作，不五条战线齐开。曾仕强：先安人。
输出物：本季唯一中心任务 + 明确的"不做什么"

**第 6 步｜设计路径：大处取势，小处试点**
科特：设 6—18 个月短期胜利。彼得斯：多做尝试、勇于失败、再尝试。圣吉：小范围"演练场"跑通再推广。明茨伯格：允许战略涌现。
输出物：路径图 + 试点范围 + 短期胜利指标

**第 7 步｜配资源：钱、人、时间是否撑得住**
唐诺森：融资能力要与增长抱负平衡。德鲁克：资源投向机会而非问题。哈默尔：优先"增加分子"，别习惯性"减少分母"（裁员）。迪奇：关键岗位优先从内部人才池取。
输出物：资源缺口清单 + 优先级

**第 8 步｜固定周期复盘：用成果改，不用理由改**
德鲁克：验证在于成果。科特：受阻时回溯八步找断点，不加大压力。迪奇：判断力是可训练技能，用真实案例打磨。曾仕强：时变了，道就要变。
输出物：复盘表（原判据／实际结果／偏差原因／下轮调整）

## 四、论据工具箱（按说服力排序）

1. **顾客事实**（德鲁克、彼得斯）— 顾客愿付钱才是真能力
2. **大样本长期实证**（祖克 1854/8000/2000 家；科特 70% 失败率；唐诺森 12 家×10 年）
3. **成果与绩效数据**（德鲁克）
4. **产业结构分析**（波特）
5. **系统结构图**（圣吉：因果回路 + 延迟 + 杠杆点）
6. **现场一手观察**（明茨伯格、彼得斯）
7. **先锋企业案例**（哈默尔、祖克：海尔、Nucor、耐克、佳能）
8. **失败案例归因**（科特、哈默尔、祖克）
9. **类比推理**（明茨伯格"工匠"、哈默尔借不守常规的组织）
10. **人性观察与经典义理**（曾仕强：人心安否、是否合理）

**反面清单（这些不算论据）**
- "行业都这么做" → 波特：这只是运营效益
- "我们一直这样" → 圣吉：今天的问题来自昨天的解决方法
- "老板/总部要求" → 明茨伯格：先去现场看看
- 靠裁员把短期 ROI 做高 → 哈默尔：这是"收割策略"
- 愿景口号本身 → 科特：愿景必须能用来否决项目

## 五、必查变量清单（决策前打勾）

**通用六项**：顾客是谁 / 五力最紧的约束 / 核心利润集中度 / 组织复杂度 / 关键岗位接班人 / 融资能力 vs 增长抱负

**生意侧追加**：取舍是否真实 / 相邻扩张离核心几步 / 是否偏离本行 / 增长公式是否老化

**组织侧追加**：人心安不安 / 制度有无弹性 / 紧迫感真假 / 指导联盟三类人齐不齐 / 是否早宣布胜利 / 反馈回路与延迟 / 是否用症状解 / 管理原则停在哪个世纪 / 管理者时间花在哪 / 涌现战略比例 / 与一线的距离 / 是否宽严并济

## 六、不确定性环境的决策模式库（核心）

**情境 A｜方向不明，不必马上决定**
德鲁克：回到"我们的事业是什么"。明茨伯格：到现场观察，别指望规划凭空生成战略。彼得斯：先做再完善。
→ 做 3 个小实验，各设学习目标，不写大规划。

**情境 B｜信息不足，却必须现在拍板**
德鲁克：一次只做一件最重要的事。明茨伯格：承认"软信息"与直觉，先行动再修正。迪奇：这次判断就是下次的训练素材。
→ 先立判据、设反转信号，再下决心。

**情境 C｜实力明显弱于对手**
波特：用集中化，选竞争力量更有利的细分。祖克：走相邻区，"stem directly from what the company already knows and does best"。
→ 找对手结构上无法经济匹配的窄口，集中全部资源。

**情境 D｜局面突变 / 外部冲击**
彼得斯："cherish impermanence – and thrive on chaos"。科特：变革不再是例外而是常规。曾仕强：经权之道，原则不变做法变。祖克：动荡期更要回到核心。
→ 先稳住核心现金流，再谈新机会。

**情境 E｜内部分歧、看不清对错**
曾仕强：先安人，人心不安任何方案都走样。圣吉：先暴露假设再讨论结论，警惕"管理团队的迷思"。哈默尔：让尽可能多的人参与定义未来。
→ 不在会上强行统一，先摊开假设，用试点让事实说话。

**情境 F｜时机窗口出现**
彼得斯：要么创新，要么死亡。祖克：成功的公司对相邻动作系统排序并"carefully time their efforts"。哈默尔：立"战略意图"。
→ 先确认融资能力撑得住（唐诺森），再抓窗口。

**情境 G｜已经出错了**
德鲁克：以成果检验，错了就在下轮目标周期改。圣吉："不去责怪"，先查系统结构。科特：回溯八步找断点，不加大压力。曾仕强：将心比心修正到"合理"。
→ 先查结构 → 再定责任 → 最后改人。

## 七、八领域决策矩阵

### 1. 战略与定位
德鲁克：由顾客定义事业｜波特：五力→通用战略→价值链｜祖克：聚焦核心→相邻扩张→重定义核心｜哈默尔：战略意图+今日/未来六问｜彼得斯：不离本行｜明茨伯格：用 5P 检查｜曾仕强：求合理不为大而大

### 2. 组织与治理
德鲁克：能分权的一律分权｜哈默尔：去科层、自组织｜明茨伯格：adhocracy 适合创新｜彼得斯：管理层不超五层｜曾仕强：制度留"例外"口子｜祖克：定期做复杂度审计

### 3. 人才与领导力
迪奇：建人才池，把继任当过程｜德鲁克：正直不可妥协，放长处不改造短处｜彼得斯：把人当成年人、宽严并济｜曾仕强：人不是资源，给平台、主管以身作则｜哈默尔：组织要配得上人｜科特：领导力培养绑进变革项目

### 4. 市场与客户
德鲁克：顾客决定企业是什么｜彼得斯："Customers reign supreme"，但有时要故意不听顾客｜祖克：80% 成功扩张源于客户驱动｜波特：买方力量强→差异化｜明茨伯格：压缩信息层级｜曾仕强：以"让对方安心"为标准

### 5. 运营与执行
德鲁克：成效>效率，先砍"不该做的事"｜彼得斯：先做再完善｜明茨伯格：主动腾出时间规划未来｜圣吉：识别"延迟"，别因短期没反应加码｜科特：列障碍清单逐条清除｜曾仕强：先划边界，边界内不干预

### 6. 财务与资本
唐诺森：管"公司财富"，先校准债务能力再定增长｜德鲁克：利润是检验指标不是目的｜哈默尔：警惕"收割策略"｜祖克：多元化占企业灾难 75%｜波特：高增长≠高盈利

### 7. 创新与变革
科特：八步缺一不可，别早宣布胜利｜哈默尔：管理创新>战略创新>产品创新>运营创新｜圣吉：改结构不改人，警惕"转移负担"｜明茨伯格：渐进为主，革命要识别时机｜彼得斯：永久性革命｜曾仕强：先变观念再变制度

### 8. 文化与价值观
彼得斯：最大的挑战是管理"软性的东西"｜科特：文化是最后一步，先改行为后改价值观｜曾仕强：中道（仁、义、礼）｜德鲁克：赋予责任感而非追求满意度｜迪奇：价值观是"可传授的观点"的一半｜圣吉：共同愿景必须真正共享

## 八、执行清单（会前对照，逐条打勾）

1. 这是生意问题还是管理问题？归类对了没？
2. 有一线观察记录吗？几条顾客原话？
3. 五力画了吗？最紧的约束是哪个？

## 九、使用纪律

1. **引用必须带人物与出处**，格式 `（人物｜出处｜来源）`。**不得捏造引文。**
2. **证据强度如实标注**：唐诺森（弱）、迪奇与曾仕强（中）的公开素材明显少于其余八位，凡薄弱处标〔证据较弱〕，不为凑内容而编造。

5. **只做方法论提取**：不对人物、企业做价值判断。
