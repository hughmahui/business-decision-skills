# 一、思想纲领（4 条）

## 纲领一：一切从客观实际出发，用实践检验并修正认识——"实事求是"的认识论纲领

他判断是非的唯一尺度不是书本、不是上级、不是主观愿望，而是客观实践的结果。认识被明确描述为一个"实践—认识—再实践—再认识"的循环，而且这个循环是**开放的、允许被实践推翻的**：计划"部分地或全部地不合于实际"被视为常态而非例外，因此"善于改正"被写成革命指导者的必备能力。

- 他把真理标准完全交给客观实践：《实践论》"判定认识或理论之是否真理，不是依主观上觉得如何而定，而是依客观上社会实践的结果如何而定。"
- 他把"计划被推翻"写进认识论的常规流程：《实践论》"原定的思想、理论、计划、方案，部分地或全部地不合于实际，部分错了或全部错了的事，都是有的。"
- 他把"改正"作为指导者的核心素质：《实践论》"真正的革命的指导者，不但在于当自己的思想、理论、计划、方案有错误时须得善于改正"
- 他给出"实事求是"的操作定义：《改造我们的学习》"'实事'就是客观存在着的一切事物，'是'就是客观事物的内部联系，即规律性，'求'就是我们去研究。"
- 他要求用材料而非热情作判断：《改造我们的学习》"不凭主观想象，不凭一时的热情，不凭死的书本，而凭客观存在的事实，详细地占有材料"
- 他把"结合实际"作为学习的唯一目的：《整顿党的作风》"对于马克思主义的理论，要能够精通它、应用它，精通的目的全在于应用。"

## 纲领二：把"矛盾分析"作为认识世界的唯一入口——先找主要矛盾，再按矛盾性质选方法

他不是按现象罗列问题，而是先把事物拆成矛盾、再在矛盾群中"全力找出主要矛盾"，并且强调**矛盾性质决定解决方法**：对抗性矛盾与非对抗性矛盾、不同质的矛盾，方法绝不能通用。

- 他把辩证法直接定义为"找方法"的工具：《矛盾论》"这个辩证法的宇宙观，主要地就是教导人们要善于去观察和分析各种事物的矛盾的运动，并根据这种分析，指出解决矛盾的方法。"
- 他把抓主要矛盾写成决策的第一动作：《矛盾论》"研究任何过程，如果是存在着两个以上矛盾的复杂过程的话，就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。"
- 他明确反对平均用力：《矛盾论》"不能把过程中所有的矛盾平均看待，必须把它们区别为主要的和次要的两类"
- 他强调方法必须匹配矛盾性质：《矛盾论》"矛盾和斗争是普遍的、绝对的，但是解决矛盾的方法，即斗争的形式，则因矛盾的性质不同而不相同。"
- 他把"具体分析"提到灵魂高度：《矛盾论》"马克思主义的最本质的东西，马克思主义的活的灵魂，就在于具体地分析具体的情况。"
- 他把"不否定一切"作为分析纪律：《学习和时局》"对于任何问题应取分析态度，不要否定一切。"

## 纲领三：调查研究是决策的前置工序，不是可选项——"没有调查，没有发言权"

在他这里，调查不是文牍流程，而是"解决问题"本身。结论的产生顺序被严格规定：先调查，后结论，绝不允许倒置。并且调查有明确的技术规范（开调查会、定纲目、亲身出马、自己做记录）。

- 他把调查设为发言权的前提：《反对本本主义》"你对于某个问题没有调查，就停止你对于某个问题的发言权。"
- 他把结论的顺序锁死：《反对本本主义》"一切结论产生于调查情况的末尾，而不是在它的先头。"
- 他用比喻压缩这一方法论：《反对本本主义》"调查就像'十月怀胎'，解决问题就像'一朝分娩'。调查就是解决问题。"
- 他要求负责人亲自到场，拒绝二手材料：《反对本本主义》"凡担负指导工作的人……一定都要亲身从事社会经济的实际调查，不能单靠书面报告，因为二者是两回事。"
- 他要求决策者具备量化底数：《党委会的工作方法》"任何质量都表现为一定的数量，没有数量也就没有质量。"
- 他规定了调查会的最低人数以避免偏听：《反对本本主义》"至少需要三人，不然会囿于见闻，不符合真实情况。"

## 纲领四：依靠群众、从群众中来到群众中去——把"群众"当作力量来源、信息渠道与检验标准

"群众"在他这里有三重功能：**力量来源**（战争的伟力根源）、**信息渠道**（意见从群众中集中起来）、**检验与动员标准**（群众觉悟程度决定行动时机）。因此领导方法被写成"从群众中来，到群众中去"的无限循环。

- 他把群众定位为力量的根源：《论持久战》"战争的伟力之最深厚的根源，存在于民众之中。"
- 他把群众路线写成认识论公式：《关于领导方法的若干问题》"凡属正确的领导，必须是从群众中来，到群众中去。"
- 他把"群众是否接受"作为政策检验：《论联合政府》"凡属正确的任务、政策和工作作风，都是和当时当地的群众要求相适合，都是联系群众的"
- 他把群众态度作为行动时机的开关：《对晋绥日报编辑人员的谈话》"当着群众还不觉悟的时候，我们要进攻，那是冒险主义。群众不愿干的事，我们硬要领导他们去干，其结果必然失败。"
- 他把解决具体生活问题作为动员的前提：《关心群众生活，注意工作方法》"真正的铜墙铁壁是什么？是群众，是千百万真心实意地拥护革命的群众。"
- 他把政策公开作为动员手段：《对晋绥日报编辑人员的谈话》"我们的政策，不光要使领导者知道，干部知道，还要使广大的群众知道。"

# 二、思想逻辑（认识世界的链条）

下面是一条完整的"判断生成链"。每一步都标注了他本人写下的操作方法与对应篇目。

```
【第 0 步｜定位研究对象——先问"这是什么性质的东西"】
   │  操作：先认清对象所处的社会性质/国情，再谈其他一切
   │  依据：《中国革命和中国共产党》"认清中国社会的性质，就是说，认清中国的国情，乃是认清一切革命问题的基本的根据。"
   │         《中国革命战争的战略问题》"我们不但要研究一般战争的规律，还要研究特殊的革命战争的规律，还要研究更加特殊的中国革命战争的规律。"
   ▼

【第 1 步｜获取判断——靠调查占有材料，不靠本本、不靠热情】
   │  操作：亲身调查、开调查会、定调查纲目、自己做记录；占有"十分丰富（不是零碎不全）和合于实际（不是错觉）"的材料
   │  依据：《反对本本主义》"你对于某个问题没有调查，就停止你对于某个问题的发言权。"
   │         《改造我们的学习》"不凭主观想象，不凭一时的热情，不凭死的书本，而凭客观存在的事实，详细地占有材料"
   │         《实践论》"只有感觉的材料十分丰富（不是零碎不全）和合于实际（不是错觉），才能根据这样的材料造出正确的概念和论理来。"
   ▼

【第 2 步｜加工材料——去粗取精、去伪存真、由此及彼、由表及里】
   │  操作：把感觉材料"改造制作"成概念、判断、推理，从现象进到本质、从片面进到全体
   │  依据：《实践论》"将丰富的感觉材料加以去粗取精、去伪存真、由此及彼、由表及里的改造制作工夫，造成概念和理论的系统"
   │         《星星之火，可以燎原》"我们看事情必须要看它的实质，而把它的现象只看作入门的向导，一进了门就要抓住它的实质"
   │         《中国革命战争的战略问题》"指挥员的正确的部署来源于正确的决心，正确的决心来源于正确的判断，正确的判断来源于周到的和必要的侦察，和对于各种侦察材料的联贯起来的思索。"
   ▼

【第 3 步｜分析矛盾——拆矛盾、找主要矛盾、看矛盾各方面的地位与转化】
   │  操作：(a) 列出全部矛盾；(b) 全力找出主要矛盾；(c) 区分主要方面/次要方面；(d) 判断对抗性还是非对抗性；(e) 看阶段变化
   │  依据：《矛盾论》"就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。"
   │         《矛盾论》"研究问题，忌带主观性、片面性和表面性。"
   │         《矛盾论》"一切矛盾着的东西，互相联系着，不但在一定条件之下共处于一个统一体中，而且在一定条件之下互相转化"
   │         《矛盾论》"矛盾和斗争是普遍的、绝对的，但是解决矛盾的方法，即斗争的形式，则因矛盾的性质不同而不相同。"
   │         《关于正确处理人民内部矛盾的问题》"敌我之间和人民内部这两类矛盾的性质不同，解决的方法也不同。简单地说起来，前者是分清敌我的问题，后者是分清是非的问题。"
   ▼

【第 4 步｜估量力量对比——把敌我双方的全部特点逐项对照，不看单点】
   │  操作：把强弱、大小、进步/退步、多助/寡助等"互相反对的基本特点"全部摆出来做比较研究，拒绝只看"强弱"一个矛盾
   │  依据：《论持久战》"中日战争不是任何别的战争，乃是半殖民地半封建的中国和帝国主义的日本之间在二十世纪三十年代进行的一个决死的战争。全部问题的根据就在这里。"
   │         《论持久战》"亡国论者看重了强弱一个矛盾，把它夸大起来作为全部问题的论据，而忽略了其他的矛盾。"
   │         《中国革命战争的战略问题》"熟识敌我双方各方面的情况，找出其行动的规律，并且应用这些规律于自己的行动。"
   │         《党委会的工作方法》"胸中有'数'。……任何质量都表现为一定的数量，没有数量也就没有质量。"
   ▼

【第 5 步｜定策略——按矛盾性质与力量对比选方法，并给趋势"描画轮廓"】
   │  操作：(a) 不同质的矛盾用不同质的方法；(b) 战略上藐视、战术上重视；(c) 战略持久、战役速决；(d) 集中兵力打歼灭战；(e) 为长期趋势描画阶段性轮廓
   │  依据：《矛盾论》"不同质的矛盾，只有用不同质的方法才能解决。"
   │         《论持久战》"客观现实的行程将是异常丰富和曲折变化的，谁也不能造出一本中日战争的'流年'来；然而给战争趋势描画一个轮廓，却为战略指导所必需。"
   │         《中国革命战争的战略问题》"我们的战略是'以一当十'，我们的战术是'以十当一'，这是我们制胜敌人的根本法则之一。"
   │         《集中优势兵力，各个歼灭敌人》"这种战法的效果是：一能全歼；二能速决。"
   │         《目前抗日统一战线中的策略问题》"这三个原则，换一句话来讲，就是'有理'，'有利'，'有节'。"
   ▼

【第 6 步｜执行——先一般号召、后个别突破，抓中心并"抓紧"】
   │  操作：一般号召＋个别指导相结合；先试点取得经验再推广；一个时期只有一个中心工作；抓而不紧等于不抓
   │  依据：《关于领导方法的若干问题》"一是一般和个别相结合，二是领导和群众相结合。"
   │         《关于领导方法的若干问题》"突破一点，取得经验，然后利用这种经验去指导其他单位"
   │         《关于领导方法的若干问题》"在任何一个地区内，不能同时有许多中心工作，在一定时间内只能有一个中心工作"
   │         《党委会的工作方法》"抓而不紧，等于不抓。"
   │         《党委会的工作方法》"党委要抓紧中心工作，又要围绕中心工作而同时开展其他方面的工作。"
   ▼

【第 7 步｜修正——把执行过程当作第二个认识过程，依新情况改计划】
   │  操作：执行中重新检查；不符合就构成新判断、定新决心、改计划；部分改变是常有的，全部改变也间或有之
   │  依据：《中国革命战争的战略问题》"如果计划和情况不符合，或者不完全符合，就必须依照新的认识，构成新的判断，定下新的决心，把已定计划加以改变，使之适合于新的情况。"
   │         《中国革命战争的战略问题》"关键，就在于把主观和客观二者之间好好地符合起来。"
   │         《实践论》"实践、认识、再实践、再认识，这种形式，循环往复以至无穷，而实践和认识之每一循环的内容，都比较地进到了高一级的程度。"
   │         《实践论》"许多时候须反复失败过多次，才能纠正错误的认识，才能到达于和客观过程的规律性相符合"
   ▼

【回到第 0 步｜过程推移后，认识必须跟着推移】
       依据：《实践论》"革命时期情况的变化是很急速的，如果革命党人的认识不能随之而急速变化，就不能引导革命走向胜利。"
              《实践论》"我们的结论是主观和客观、理论和实践、知和行的具体的历史的统一"
```

**这条链条的三条硬约束**
1. 顺序不可倒置：结论必须在调查末尾产生——《反对本本主义》"一切结论产生于调查情况的末尾，而不是在它的先头。"
2. 主观必须不断向客观靠拢：《中国革命战争的战略问题》"关键，就在于把主观和客观二者之间好好地符合起来。"
3. 每个循环都要升级，不是原地转圈：《实践论》"实践和认识之每一循环的内容，都比较地进到了高一级的程度。"

# 三、分领域决策逻辑

## 1. 军事与战略

**核心判断原则**
- **战争目的只有一条：保存自己、消灭敌人**；一切形式（运动战、阵地战、游击战）都按"歼灭还是消耗"的效果来取舍。
- **敌我特点决定战略，不照抄任何外国/过去经验**：《中国革命战争的战略问题》"我们不但要研究一般战争的规律，还要研究特殊的革命战争的规律，还要研究更加特殊的中国革命战争的规律。"
- **全局观高于局部胜负**：指挥员注意力必须放在对全局有决定意义的关节上。
- **主动性是军队的命脉**：《论持久战》"行动自由是军队的命脉，失了这种自由，军队就接近于被打败或被消灭。"

**典型决策动作**
- 战略上持久、战役战斗上速决；防御中的进攻、内线中的外线。
- 集中绝对优势兵力打一路、打一点，得手后扩张战果、各个歼灭。
- 以歼灭敌人有生力量为主要目标，不以保守或夺取地方为主要目标。
- 打不赢就走，用空间换时间；赌命运的战略决战根本不干。

**原文依据**
- 《集中优势兵力，各个歼灭敌人》"集中绝对优势的兵力，即集中六倍、或五倍、或四倍于敌的兵力、至少也要有三倍于敌的兵力"
- 《集中优势兵力，各个歼灭敌人》"这个旅（或团），应当是敌军诸旅中较弱的，或者是较少援助的，或者是其驻地的地形和民情对我最为有利而对敌不利的。"
- 《集中优势兵力，各个歼灭敌人》"以歼灭敌军有生力量为主要目标，不以保守或夺取地方为主要目标。"

## 2. 经济建设

**核心判断原则**
- **经济决定财政，不是财政决定经济**：《抗日时期的经济问题和财政问题》"他们不知道财政政策的好坏固然足以影响经济，但是决定财政的却是经济。"
- **一条战线反保守、一条战线反冒进**：既反对收缩开支的保守观点，也反对脱离条件的大计划。
- **目标与手段可以反向**：想要更多重工业，就得先多投农业轻工业（以退为进的投入次序）。
- **统筹兼顾、量力安排**：从全部人口出发作计划，使人民"所得大于所失"。

**典型决策动作**
- 提出"发展经济，保障供给"总方针；自己动手建立公营经济。
- 以农业为经济建设中心，同时发展工业、外贸、合作社。
- 调整投资比例：加重农业轻工业，反而加速重工业。
- 调动中央与地方两个积极性，给地方更多独立性。
- 中央定政治前提（独立、自由、民主、统一）后再谈工业化。

**原文依据**
- 《抗日时期的经济问题和财政问题》"发展经济，保障供给，是我们的经济工作和财政工作的总方针。"
- 《抗日时期的经济问题和财政问题》"党的路线是正确的发展路线，一方面要反对陈旧的保守的观点，另一方面又要反对空洞的不切实际的大计划。"
- 《抗日时期的经济问题和财政问题》"使人民有所失同时又有所得，并且使所得大于所失，才能支持长期的抗日战争。"
- 《论十大关系》"我们现在发展重工业可以有两种办法……从长远观点来看，前一种办法会使重工业发展得少些和慢些"
- 《论十大关系》"有中央和地方两个积极性，比只有一个积极性好得多。"
- 《论联合政府》"没有独立、自由、民主和统一，不可能建设真正大规模的工业。没有工业，便没有巩固的国防"
- 《我们的经济政策》"我们的经济政策的原则，是进行一切可能的和必须的经济方面的建设，集中经济力量供给战争，同时极力改良民众的生活"
- 《关于正确处理人民内部矛盾的问题》"我们的方针是统筹兼顾、适当安排。"
- 《组织起来》"把一切老百姓的力量、一切部队机关学校的力量、一切男女老少的全劳动力半劳动力……动员起来，组织起来"

## 3. 外交

**核心判断原则**
- **先分类，再定策**：把帝国主义按"侵略/未侵略""同盟德意/对立英美""政府/人民""政策的前一时期/现时期"逐层区分，在不同区别上建立不同政策。
- **本质是纸老虎，具体是真老虎**：战略上藐视（长期、本质、全体），战术上重视（局部、每一个具体斗争）。
- **自力更生为主、外援为辅**：《论政策》"我们的根本方针……是在坚持独立战争和自力更生的原则下尽可能地利用外援"
- **利用矛盾、争取多数、反对少数、各个击破**：这是贯穿外交与统战的同一策略原则。

**典型决策动作**
- 在明确"骑墙不行、第三条道路没有"后做阵营选择，但把"做生意"与"阵营选择"分开处理。
- 只反对妨碍做生意的内外反动派，"此外并不反对任何人"。
- 承认战争危险存在，同时指出人民力量可以克服它，避免被悲观估计吓住。
- 对国际形势给出"较早妥协或较迟妥协"的条件式判断，而非宿命式判断。

**原文依据**
- 《论政策》"我们的策略原则，仍然是利用矛盾，争取多数，反对少数，各个击破。"

- 《和美国记者安娜·路易斯·斯特朗的谈话》"从长远的观点看问题，真正强大的力量不是属于反动派，而是属于人民。"
- 《和美国记者安娜·路易斯·斯特朗的谈话》"这原因不是别的，就在于反动派代表反动，而我们代表进步。"
- 《论人民民主专政》"一边倒，是孙中山的四十年经验和共产党的二十八年经验教给我们的，深知欲达到胜利和巩固胜利，必须一边倒。"

- 《论人民民主专政》"我们就有可能在平等、互利和互相尊重领土主权的基础之上和一切国家建立外交关系了。"
- 《论人民民主专政》"在帝国主义存在的时代，任何国家的真正的人民革命，如果没有国际革命力量在各种不同方式上的援助，要取得自己的胜利是不可能的。"
- 《关于目前国际形势的几点估计》"世界人民的民主力量超过世界反动力量，并且正在向前发展，必须和必能克服战争危险。"
- 《论十大关系》"一切民族、一切国家的长处都要学……但是，必须有分析有批判地学，不能盲目地学，不能一切照抄，机械搬用。"

## 4. 社会治理

**核心判断原则**
- **先分清两类矛盾，再选工具**：敌我矛盾用专政，人民内部矛盾用民主、用"团结—批评—团结"。
- **大规模人口是决策的硬约束**：作计划、办事、想问题都要从人口基数出发。
- **两条群众原则**：一条是群众的实际需要，一条是群众的自愿；缺一即失败。
- **具体生活问题即政治问题**：柴米油盐解决好了，群众才会响应更高的政治号召。

**典型决策动作**
- 用"团结——批评——团结"公式处理一切人民内部矛盾，并推广到工厂、合作社、学校、机关。
- 用"统筹兼顾、适当安排"处理粮食、灾荒、就业、教育、少数民族等问题，与各方面协商。
- 以"惩前毖后、治病救人"处理犯错误者：一要看，二要帮。
- 反革命按"杀、关、管、放"分类处理，机关学校内部坚持"一个不杀，大部不捉"。
- 反对官僚主义与命令主义，改用"耐心说服"的具体工作方法。

**原文依据**
- 《关于正确处理人民内部矛盾的问题》"敌我之间和人民内部这两类矛盾的性质不同，解决的方法也不同。简单地说起来，前者是分清敌我的问题，后者是分清是非的问题。"
- 《关于正确处理人民内部矛盾的问题》"'团结——批评——团结'。……就是从团结的愿望出发，经过批评或者斗争使矛盾得到解决，从而在新的基础上达到新的团结。"
- 《关于正确处理人民内部矛盾的问题》"我们作计划、办事、想问题，都要从我国有六亿人口这一点出发，千万不要忘记这一点。"
- 《论十大关系》"对待反革命分子的办法是：杀、关、管、放。"（《革命和反革命的关系》）
- 《论十大关系》"对于犯了错误的同志，有人说要看他们改不改。我说单是看还不行，还要帮助他们改。"
- 《文化工作中的统一战线》"一条是群众的实际上的需要……一条是群众的自愿，由群众自己下决心，而不是由我们代替群众下决心。"
- 《关心群众生活，注意工作方法》"一切群众的实际生活问题，都是我们应当注意的问题。"
- 《关心群众生活，注意工作方法》"不抛弃命令主义的工作方法而采取耐心说服的工作方法，那末，什么任务也是不能实现的。"
- 《对晋绥日报编辑人员的谈话》"文武之道，一张一弛"／"你们的缺点主要是把弓弦拉得太紧了。拉得太紧，弓弦就会断。"

## 5. 治党建党

**核心判断原则**
- **三大作风是区别于其他政党的标志**：理论联系实际、密切联系群众、自我批评。
- **思想教育是团结全党进行政治斗争的中心环节**。
- **集体领导与个人负责不可偏废**；个人包办必须纠正。
- **批评的目的是救人不是整人**：《整顿党的作风》"我们揭发错误、批判缺点的目的，好像医生治病一样，完全是为了救人，而不是为了把人整死。"

**典型决策动作**
- 用整风运动解决思想矛盾，方法定为"惩前毖后，治病救人"，明确抛弃"残酷斗争，无情打击"。
- 一切重要问题交委员会讨论、充分发表意见、作出明确决定再分头执行；会前对分歧问题先个别商谈。
- 领导方法固定为两条：一般和个别相结合、领导和群众相结合；在一个单位先形成以首要负责人为核心的少数积极分子骨干。
- 通过有关下级机关的主要负责人向下传达任务（一元化），避免上级单线找下级部门。
- 会议要有"安民告示"；讲话写文章简明扼要；书记要当好"班长"；委员之间"互通情报"。

**原文依据**
- 《论联合政府》"这主要的就是理论和实践相结合的作风，和人民群众紧密地联系在一起的作风以及自我批评的作风。"
- 《论联合政府》"共产党人必须随时准备坚持真理……共产党人必须随时准备修正错误"
- 《论联合政府》"房子是应该经常打扫的，不打扫就会积满了灰尘"
- 《整顿党的作风》"对于以前的错误一定要揭发，不讲情面，要以科学的态度来分析批判过去的坏东西，以便使后来的工作慎重些，做得好些。"
- 《关于健全党委制》"一切重要问题……均须交委员会讨论，由到会委员充分发表意见，做出明确决定，然后分别执行。"
- 《关于健全党委制》"集体领导和个人负责，二者不可偏废。"
- 《关于领导方法的若干问题》"我们共产党人无论进行何项工作，有两个方法是必须采用的，一是一般和个别相结合，二是领导和群众相结合。"
- 《关于领导方法的若干问题》"任何有群众的地方，大致都有比较积极的、中间状态的和比较落后的三部分人。"

- 《党委会的工作方法》"我们不仅要善于团结和自己意见相同的同志，而且要善于团结和自己意见不同的同志一道工作。"
- 《党委会的工作方法》"划清两种界限。首先，是革命还是反革命？"
- 《论十大关系》"究竟是一个党好，还是几个党好？现在看来，恐怕是几个党好。……就是长期共存，互相监督。"

## 6. 文化与宣传

**核心判断原则**
- **政治标准第一、艺术标准第二，但要求二者统一**：《在延安文艺座谈会上的讲话》"我们的要求则是政治和艺术的统一，内容和形式的统一"
- **动机看效果**：社会实践及其效果是检验主观愿望的标准。
- **政策必须让群众知道，否则工作做不好**：《对晋绥日报编辑人员的谈话》"我们的政策，不光要使领导者知道，干部知道，还要使广大的群众知道。"
- **文化统一战线的两条原则：团结，以及批评、教育和改造**；先团结后改造。

**典型决策动作**
- 确定"民族的形式、新民主主义的内容"的文化形态；对外国文化"排泄其糟粕，吸收其精华"，绝不生吞活剥。
- 文艺批评同时设政治标准与艺术标准，并进行"两条战线斗争"。
- 办报靠全党、全体人民群众来办，不靠少数人关起门来办；报社人员先向群众学习。
- 教育、艺术、医药三条线同时改造旧形式（旧村塾、旧戏班、旧医生），先团结再改造。
- 宣传分寸随形势调整，纠正"左"的偏向时"弛"一下，避免弓弦拉断。

**原文依据**
- 《在延安文艺座谈会上的讲话》"文艺批评有两个标准，一个是政治标准，一个是艺术标准。"
- 《在延安文艺座谈会上的讲话》"任何阶级社会中的任何阶级，总是以政治标准放在第一位，以艺术标准放在第二位的。"
- 《在延安文艺座谈会上的讲话》"社会实践及其效果是检验主观愿望或动机的标准。"
- 《新民主主义论》"必须经过自己的口腔咀嚼和胃肠运动……排泄其糟粕，吸收其精华"
- 《新民主主义论》"民族的形式，新民主主义的内容——这就是我们今天的新文化。"
- 《文化工作中的统一战线》"统一战线的原则有两个：第一个是团结，第二个是批评、教育和改造。"
- 《文化工作中的统一战线》"没有文化的军队是愚蠢的军队，而愚蠢的军队是不能战胜敌人的。"
- 《对晋绥日报编辑人员的谈话》"善于把党的政策变为群众的行动……这是一项马克思列宁主义的领导艺术。我们的工作犯不犯错误，其界限也在这里。"
- 《对晋绥日报编辑人员的谈话》"报纸工作人员为了教育群众，首先要向群众学习。"
- 《新民主主义论》"只有千百万人民的革命实践，才是检验真理的尺度。"

## 7. 统一战线

**核心判断原则**
- **先分类（分清敌友）再定策**：《中国社会各阶级的分析》"谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。"
- **三个不可分离的环节**：发展进步势力、争取中间势力、反对顽固势力。
- **以斗争求团结**：《目前抗日统一战线中的策略问题》"以斗争求团结则团结存，以退让求团结则团结亡"
- **中间派的态度容易动摇且必然分化**，必须针对动摇做说服与批评。

**典型决策动作**
- 对外两面派实行"革命的两面政策"：尚能抗日的一面联合，反共的一面孤立；对汉奸亲日派中的两面分子也区别对待。
- 斗争严格执行"有理、有利、有节"三原则：自卫（人不犯我我不犯人）、胜利（不斗则已斗则必胜，择最反动者先打击）、休战（适可而止、主动再讲团结）。
- 争取中间势力必须同时具备三个条件：我们有充足力量、尊重其利益、对顽固派斗争能逐步取胜。
- 政权人员按"三三制"分配，并保证最下级政权可因地制宜变动以防豪绅把持。
- 敌占区与国统区采取"荫蔽精干、长期埋伏、积蓄力量、以待时机"。

**原文依据**
- 《中国社会各阶级的分析》"那动摇不定的中产阶级，其右翼可能是我们的敌人，其左翼可能是我们的朋友——但我们要时常提防他们"
- 《目前抗日统一战线中的策略问题》"必须采取发展进步势力、争取中间势力、反对顽固势力的策略，这是不可分离的三个环节"
- 《目前抗日统一战线中的策略问题》"第一是自卫原则。人不犯我，我不犯人，人若犯我，我必犯人。"
- 《目前抗日统一战线中的策略问题》"第二是胜利原则。不斗则已，斗则必胜，决不可举行无计划无准备无把握的斗争。"
- 《目前抗日统一战线中的策略问题》"第三是休战原则。……适可而止，使这一斗争告一段落。"
- 《目前抗日统一战线中的策略问题》"这些条件是：（1）我们有充足的力量；（2）尊重他们的利益；（3）我们对顽固派作坚决的斗争，并能一步一步地取得胜利。"
- 《论政策》"现在的抗日民族统一战线政策，既不是一切联合否认斗争，又不是一切斗争否认联合，而是综合联合和斗争两方面的政策。"

- 《关于打退第二次反共高潮的总结》"斗争必须是有理、有利、有节的，三者缺一，就要吃亏。"
- 《论人民民主专政》"团结国内国际的一切力量击破内外反动派，我们就有生意可做了"

# 四、决策方法中的论据类型

## 类型 1：实地调查所得的一手材料（最优先、可一票否决其他论据）

他把亲身调查置于书本、上级指示之上，并给出明确技术规范。

- 《反对本本主义》"凡担负指导工作的人……一定都要亲身从事社会经济的实际调查，不能单靠书面报告，因为二者是两回事。"
- 《湖南农民运动考察报告》"我这回到湖南，实地考察了湘潭、湘乡、衡山、醴陵、长沙五县的情况。从一月四日起至二月五日止，共三十二天"
- 《反对本本主义》"要定调查纲目……要有大纲，还要有细目"
- 《党委会的工作方法》"在任何群众运动中，群众积极拥护的有多少，反对的有多少，处于中间状态的有多少，这些都必须有个基本的调查，基本的分析"

## 类型 2：阶级分析（用"经济地位 → 政治态度"推演行为）

他用经济地位推断政治态度，再据此划分敌/我/友与可靠程度，是贯穿全书的底层论据。

- 《中国社会各阶级的分析》"不可不将中国社会各阶级的经济地位及其对于革命的态度，作一个大概的分析。"
- 《反对本本主义》"我们的终极目的是要明了各种阶级的相互关系，得到正确的阶级估量，然后定出我们正确的斗争策略"
- 《中国社会各阶级的分析》"这种人胆子小，他们怕官，也有点怕革命。因为他们的经济地位和中产阶级颇接近，故对于中产阶级的宣传颇相信"
- 《目前抗日统一战线中的策略问题》"中间派的态度是容易动摇的，并且不可避免地要发生分化"

## 类型 3：数量与统计（用"数"支撑"质"，反对胸中无数）

- 《党委会的工作方法》"任何质量都表现为一定的数量，没有数量也就没有质量。"
- 《关心群众生活，注意工作方法》"长冈乡青年壮年男子百个人中有八十个当红军去了"
- 《论十大关系》"我国全部轻工业和重工业，都有约百分之七十在沿海，只有百分之三十在内地。"
- 《论十大关系》"中央认为斯大林是三分错误，七分成绩"（数量化的分寸判断）

## 类型 4：敌我力量对比的逐项对照（多维度，禁止单点归约）

- 《论持久战》"我们已把强弱、大小、进步退步、多助寡助几个敌我之间矛盾着的基本特点，作了比较研究"
- 《论持久战》"日本的长处是其战争力量之强，而其短处则在其战争本质的退步性、野蛮性，在其人力、物力之不足，在其国际形势之寡助。"
- 《论持久战》"中国的短处是战争力量之弱，而其长处则在其战争本质的进步性和正义性，在其是一个大国家，在其国际形势之多助。"
- 《集中优势兵力，各个歼灭敌人》"集中六倍、或五倍、或四倍于敌的兵力、至少也要有三倍于敌的兵力"

## 类型 5：历史类比（中外战史、古典小说、党史经验）

他大量调用历史与文学案例作类比，用来说明"以弱胜强""避免决战""情况不明必败"等抽象原则。

- 《论持久战》"中国如晋楚城濮之战，楚汉成皋之战，韩信破赵之战……都是以少击众，以劣势对优势而获胜。"
- 《论持久战》"历史上，俄国以避免决战，执行了勇敢的退却，战胜了威震一时的拿破仑。中国现在也应这样干。"
- 《矛盾论》"《水浒传》上宋江三打祝家庄，两次都因情况不明，方法不对，打了败仗。后来改变方法，从调查情形入手"
- 《矛盾论》"唐朝人魏徵说过：'兼听则明，偏信则暗。'也懂得片面性不对。"
- 《论持久战》"孙子的规律，'知彼知己，百战不殆'，仍是科学的真理。"

## 类型 6：试点经验与一般经验的互相校验

- 《关于领导方法的若干问题》"突破一点，取得经验，然后利用这种经验去指导其他单位"
- 《关心群众生活，注意工作方法》"江西的长冈乡，福建的才溪乡，扩大红军多得很呀！……什么理由呢？举几个例子就明白了。"
- 《对晋绥日报编辑人员的谈话》"崞县两个区的农民一百八十多人，开了五天会，解决了分配土地中的许多问题。"
- 《反对本本主义》"初次从事调查工作的人，要作一两回深入的调查工作……往后调查别处地方、别个问题，便容易找到门路了。"

## 类型 7：反面教训（用"失败过"当作论据，且优先引用自己的失败）

- 《中国革命战争的战略问题》"一九三二年进攻中心城市的军事冒险主义，正是后来在对付敌人第五次'围剿'中采取消极防御路线的根源。"
- 《论十大关系》"最近苏联方面暴露了他们在建设社会主义过程中的一些缺点和错误，他们走过的弯路，你还想走？"
- 《论政策》"而这两个极端的政策，都使党和革命遭受了极大的损失。"（一切联合否认斗争 ／ 一切斗争否认联合）
- 《实践论》"人们经过失败之后，也就从失败取得教训，改正自己的思想使之适合于外界的规律性，人们就能变失败为胜利"

## 类型 8：条件式推论（把结论写成"如果……则……"，而非断言）

- 《论持久战》"我们客观地而且全面地承认亡国和解放两个可能同时存在，着重指出解放的可能占优势及达到解放的条件，并为争取这些条件而努力。"
- 《关于目前国际形势的几点估计》"美、英、法同苏联的关系，不是或者妥协或者破裂的问题，而是或者较早妥协或者较迟妥协的问题。"
- 《集中优势兵力，各个歼灭敌人》"如果我军兵力多，当地敌军较弱……可以同时攻击若干部分的敌军。……如果我军兵力不足，则应对敌军所占诸城一个一个地夺取之"
- 《论持久战》"在出现了这种情形之时，不是日本进攻中国的放松，反而是它进攻中国的加紧"

# 六、不确定性环境下的决策方式

## 6.1 信息不完备时怎么办？

**答案：不等待完备，追求"一般地正确的指导"；用侦察＋推论降低不确定性；给计划以"相对的固定性"。**

他明确承认战争现象"更难捉摸，更少确实性"，但拒绝因此滑向不可知论或放弃计划。处置办法是三段：先侦察、再聪明推论、然后接受"大体适合情况"即为胜利基础；同时反对因流动性而否认计划的相对固定性。

- 《论持久战》"我们承认战争现象是较之任何别的社会现象更难捉摸，更少确实性，即更带所谓'盖然性'。"
- 《论持久战》"先之以各种侦察手段，继之以指挥员的聪明的推论和判断，减少错误，实现一般的正确指导，是做得到的。"
- 《论持久战》"敌之一方很不确实，但也有朕兆可寻，有端倪可察，有前后现象可供思索。"
- 《中国革命战争的战略问题》"然而只要做到指挥大体上适合情况，即在有决定意义的部分适合情况，那就是胜利的基础了。"
- 《论持久战》"战争的计划或方针，也只应给以相对的固定性，必须根据情况的变化和战争的流动而适时地加以更换或修改"
- 《反对本本主义》"可以召集那些明了情况的人来开个调查会，把你所谓困难问题的'来源'找到手，'现状'弄明白"

## 6.2 敌强我弱时怎么办？

**答案：战略上以一当十（藐视），战术上以十当一（重视）；避免战略决战，用局部优势累积成全局优势；能全歼则打，无把握则走。**

- 《中国革命战争的战略问题》"我们的战略是'以一当十'，我们的战术是'以十当一'，这是我们制胜敌人的根本法则之一。"
- 《论持久战》"通过这样许多战役的局部优势和局部主动地位，就能逐渐地造成战略的优势和战略的主动地位"
- 《论持久战》"在斗争中，由于主观指导的正确或错误，可以化劣势为优势，化被动为主动"
- 《论持久战》"一切有把握的战役和战斗应坚决地进行决战，一切无把握的战役和战斗应避免决战，赌国家命运的战略决战应根本避免。"
- 《论持久战》"留得青山在，不愁没柴烧，虽然丧失若干土地，还有广大的回旋余地"
- 《和美国记者安娜·路易斯·斯特朗的谈话》"一切反动派都是纸老虎。看起来，反动派的样子是可怕的，但是实际上并没有什么了不起的力量。"
- 《集中优势兵力，各个歼灭敌人》"集中兵力，采用包围迂回战术，是实施运动战即外线的速决的进攻战之必要条件。"
- 《论持久战》"我们主张一切有利条件下的决战，不论是战斗的和大小战役的，在这上面不容许任何的消极。"

## 6.3 判断错了怎么纠正？

**答案：把执行本身当作第二个认识过程；发现不符合就改判断、改决心、改计划；把"反复失败"写进正常路径。**

他把"改正"制度化：不是追责，而是流程。同时他把认识落后（右倾）与认识超前（左倾）都列为要反对的错误，纠正的方向是"主观和客观的具体的历史的统一"。

- 《中国革命战争的战略问题》"如果计划和情况不符合，或者不完全符合，就必须依照新的认识，构成新的判断，定下新的决心，把已定计划加以改变，使之适合于新的情况。"
- 《中国革命战争的战略问题》"部分地改变的事差不多每一作战都是有的，全部地改变的事也是间或有的。鲁莽家不知改变，或不愿改变，只是一味盲干，结果又非碰壁不可。"
- 《实践论》"许多时候须反复失败过多次，才能纠正错误的认识，才能到达于和客观过程的规律性相符合"
- 《实践论》"我们的结论是主观和客观、理论和实践、知和行的具体的历史的统一，反对一切离开具体历史的'左'的或右的错误思想。"
- 《关于打退第二次反共高潮的总结》"上次反共高潮曾被一部分同志估计为马日事变，这次反共高潮又被估计为四一二事变和马日事变，但是客观事实却证明了这种估计是不正确的。这些同志的错误，在于忘记了民族矛盾是基本矛盾这一点。"
- 《学习和时局》"我们许多同志缺乏分析的头脑，对于复杂事物，不愿作反复深入的分析研究，而爱作绝对肯定或绝对否定的简单结论。"
- 《关于正确处理人民内部矛盾的问题》"'团结——批评——团结'……在经过几年之后，到一九四五年……果然达到了全党团结的目的"

## 6.4 低潮时怎么办？

**答案：看实质不看现象；把"小小的力量"判断为具备发展必然性；承认低潮但拒绝悲观估量；做好艰苦工作而非流动游击。**

他的标准动作是：先承认现象上的弱小，再指出"反动统治阶级的一切组织也是弱的"，从而得出相对而非绝对的劣势判断；然后用"干柴/星火"比喻把趋势确定下来；最后落到"做艰苦工作"（建立根据地）而不是"轻便的流动游击"。

- 《星星之火，可以燎原》"我们看事情必须要看它的实质，而把它的现象只看作入门的向导，一进了门就要抓住它的实质，这才是可靠的科学的分析方法。"
- 《星星之火，可以燎原》"现在虽只有一点小小的力量，但是它的发展会是很快的。它在中国的环境里不仅是具备了发展的可能性，简直是具备了发展的必然性"
- 《星星之火，可以燎原》"现在中国革命的主观力量虽然弱，但是……反革命力量也是相对地弱的，所以中国革命的走向高潮，一定会比西欧快。"
- 《星星之火，可以燎原》"中国是全国都布满了干柴，很快就会燃成烈火。"
- 《星星之火，可以燎原》"我们三年来从斗争中所得的战术……'分兵以发动群众，集中以应付敌人。'"
- 《论持久战》"这个第二阶段，也许将经过相当长的时间。……中国将逐渐上升，日本则逐渐下降。"（相持阶段即低潮期的处理）
- 《论持久战》"此时我们的任务，在于动员全国民众，齐心一致，绝不动摇地坚持战争"
- 《关于目前国际形势的几点估计》"世界人民的民主力量超过世界反动力量，并且正在向前发展，必须和必能克服战争危险。"（针对悲观估计）

## 6.5 处境反转时怎么办？

**答案：重估主要矛盾、重划敌友边界、调整策略松紧；警惕被胜利冲昏头脑，也要警惕被失败吓倒。**

反转（由弱转强、由被围剿转反攻、由合作转摩擦）时，他的动作是：重新判定哪个矛盾是"基本的"；对分歧对象改为"即以其人之道，还治其人之身"的两面政策；胜利后主动休战、主动再讲团结；纠正偏差时同时反右与反"左"，并注意"一张一弛"。

- 《关于打退第二次反共高潮的总结》"在中国两大矛盾中间，中日民族间的矛盾依然是基本的，国内阶级间的矛盾依然处在从属的地位。"
- 《关于打退第二次反共高潮的总结》"我党的方针便是'即以其人之道，还治其人之身'，以打对打，以拉对拉，这就是革命的两面政策。"
- 《目前抗日统一战线中的策略问题》"决不可无止境地每日每时地斗下去，决不可被胜利冲昏自己的头脑。"
- 《论政策》"目前党内的主要危险倾向，仍然是过左的观点在作怪。"
- 《对晋绥日报编辑人员的谈话》"总结了反右反'左'的经验，使头脑清醒起来，你们的工作就会有改进。"
- 《对晋绥日报编辑人员的谈话》"你们的缺点主要是把弓弦拉得太紧了。拉得太紧，弓弦就会断。古人说：'文武之道，一张一弛。'"
- 《论持久战》"即在战略反攻阶段的决战亦然。那时虽然敌处劣势，我处优势，然而仍适用'执行有利决战，避免不利决战'的原则"
- 《党委会的工作方法》"力戒骄傲。这对领导者是一个原则问题，也是保持团结的一个重要条件。"
- 《论联合政府》"只要我们能吸取三个时期的经验，采取谦虚态度，防止骄傲态度……就可以保证，不但不会被敌人打散"

# 七、可直接复用的决策口诀与检查清单（18 条）

## A. 判断前（先把底数摸清）

1. **先定性，再定量**：动手前先问对象"是什么性质"，性质不清不谈对策。
   →《中国革命和中国共产党》"认清中国社会的性质，就是说，认清中国的国情，乃是认清一切革命问题的基本的根据。"

2. **没调查就没有发言权**：结论一律放在调查末尾，不得倒置。
   →《反对本本主义》"一切结论产生于调查情况的末尾，而不是在它的先头。"

3. **负责人亲自到场**：关键判断不靠书面报告，靠亲身接触。
   →《反对本本主义》"一定都要亲身从事社会经济的实际调查，不能单靠书面报告，因为二者是两回事。"

4. **胸中必须有数**：把比例、人数、百分比问到底，没有数量就没有质量。
   →《党委会的工作方法》"任何质量都表现为一定的数量，没有数量也就没有质量。"

5. **忌带三性**：主观性、片面性、表面性；至少同时看矛盾的两方。
   →《矛盾论》"研究问题，忌带主观性、片面性和表面性。"

## B. 分析时（把问题拆成矛盾）

6. **全力找主要矛盾**：矛盾成群时，先确定哪一个起领导、决定作用。
   →《矛盾论》"就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了。"

7. **矛盾分主次，也分方面**：不只分矛盾，还要分矛盾内部的主要方面与次要方面。
   →《矛盾论》"不能把过程中所有的矛盾平均看待，必须把它们区别为主要的和次要的两类"

8. **不同质的矛盾用不同质的方法**：绝不一套公式到处硬套。
   →《矛盾论》"不同质的矛盾，只有用不同质的方法才能解决。"

9. **分清两类矛盾再选工具**：敌我问题用分清敌我，内部问题用分清是非。
   →《关于正确处理人民内部矛盾的问题》"前者是分清敌我的问题，后者是分清是非的问题。"

10. **敌我对比要逐项列，不只看强弱**：强弱、大小、进步/退步、多助/寡助一起比。
   →《论持久战》"我们已把强弱、大小、进步退步、多助寡助几个敌我之间矛盾着的基本特点，作了比较研究"

11. **同时承认两种可能，然后为优势可能创造条件**：不做宿命论者，也不做速胜论者。
   →《论持久战》"客观地而且全面地承认亡国和解放两个可能同时存在，着重指出解放的可能占优势及达到解放的条件，并为争取这些条件而努力。"

## C. 定策时（按性质与条件选动作）

12. **给趋势描轮廓，但不机械定时日**：允许预测方向，禁止假装算命。
   →《星星之火，可以燎原》"马克思主义者不是算命先生，未来的发展和变化，只应该也只能说出个大的方向，不应该也不可能机械地规定时日。"

13. **战略上藐视，战术上重视**：以一当十是战略，以十当一是战术。
   →《中国革命战争的战略问题》"我们的战略是'以一当十'，我们的战术是'以十当一'，这是我们制胜敌人的根本法则之一。"

14. **有把握就决战，无把握就走**：绝不赌命运，放弃土地换时间是被允许的正确政策。
   →《论持久战》"一切有把握的战役和战斗应坚决地进行决战，一切无把握的战役和战斗应避免决战，赌国家命运的战略决战应根本避免。"

15. **斗争要"有理、有利、有节"**：自卫、必胜、适可而止，三者缺一就要吃亏。
   →《目前抗日统一战线中的策略问题》"这三个原则，换一句话来讲，就是'有理'，'有利'，'有节'。"

16. **一个时期只设一个中心，并且"抓紧"**：配合"弹钢琴"兼顾其他，但主方向只能一个。
   →《关于领导方法的若干问题》"在一定时间内只能有一个中心工作"／《党委会的工作方法》"抓而不紧，等于不抓。"

## D. 执行与修正时

17. **先试点、后推广；一般号召＋个别指导**：没有从个别单位取得经验，不作普遍指导。
   →《关于领导方法的若干问题》"突破一点，取得经验，然后利用这种经验去指导其他单位"

18. **计划随情况改，改是常态不是事故；认识落后要反右，认识超前要反"左"**：
   →《中国革命战争的战略问题》"必须依照新的认识，构成新的判断，定下新的决心，把已定计划加以改变，使之适合于新的情况。"
   →《实践论》"我们的结论是主观和客观、理论和实践、知和行的具体的历史的统一，反对一切离开具体历史的'左'的或右的错误思想。"
