# 决策

一套从《毛泽东选集》《邓小平文选》原文提炼出来的**可操作决策操作系统**。不是心得体会，每条结论都能回溯到具体篇目和原句。

核心主张：**决策能力 = 把"看不清"处理成"可行动"的能力。** 两人面对的都是极端不确定环境，真正被反复使用的是同一套骨架——先定性、再摸底、找主要矛盾、收敛中心、试点试探、复盘纠偏；差别在于毛在**力量对抗**条件下做判断，邓在**长期建设**条件下做判断，因此动作偏好不同。

## 使用路由

| 你要做什么 | 读哪里 |
|---|---|
| 有一个具体问题要拿主意 | 直接走下面「三、七步决策法」 |
| 想知道毛在具体领域怎么想 | `references/mao-thinking.md` 第三部分（按领域） |
| 想知道邓在具体领域怎么想 | `references/deng-thinking.md` 第三部分（按领域） |
| 要引用原文、核对句子 | 两份 reference 全文，每条结论后带「篇名」+ 原句 |
| 要写材料/汇报/复盘 | 按「八、执行清单」套用，再回到 reference 取原句作论据 |

### 引用体例（全文统一）
- 《书名号》= **毛泽东**著作篇名；「方头引号」= **邓小平**著作篇名。
- 「南方谈话」「谈话要点」= 「在武昌、深圳、珠海、上海等地的谈话要点」的简称。
- 素材来源：《毛泽东选集》第一至第五卷（229 篇全文）、《邓小平文选》第一至第三卷（222 篇全文），全部已存入资料库「思想」文件夹，可检索核对。

## 一、两条思想线路：先判断你在哪种局面

两人不是对立的两套方法，而是**同一骨架的两种工况**。先选工况，再选动作偏好。

| | **毛线路（对抗工况）** | **邓线路（建设工况）** |
|---|---|---|
| 环境特征 | 敌我对抗、力量悬殊、生死反转 | 长期建设、渐变形势、环境相对可预期 |
| 首要动作 | 分清敌友｜《中国社会各阶级的分析》"谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。" | 承认现实｜「尊重知识，尊重人才」"要承认落后，承认落后就有希望了。" |
| 分析主线 | 矛盾 → 力量对比 → 斗争策略 | 主要矛盾 → 中心任务 → 试点 → 推开 |
| 时间偏好 | 长期方向明确、短期阶段可变 | 政策稳定不变、年度报告复盘纠偏 |
| 风险姿态 | 敢赌局部，绝不赌全局｜"赌国家命运的战略决战应根本避免" | 敢冒小险，绝不冒系统险｜"每年领导层都要总结经验，对的就坚持，不对的赶快改" |
| 典型误用 | 在建设期频繁搞敌我划分 | 在对抗期用"再看一看"拖掉时机 |

**选型规则**：有明确对手且对手在压制你 → 走毛；环境相对和平但方向不明 → 走邓；两者都不确定时，**用邓的方法推进，用毛的方法做底线判断**。

## 二、从"思想纲领"到"决策逻辑"的推导链

这是整套方法的骨架。上面是「信什么」，下面是「怎么做」——中间那一步是推导，不是并列。

### 思想的四块基石（两组共用）
1. **实事求是**——真理标准是客观实践结果，不是书本、不是上级、不是主观愿望｜《实践论》"判定认识或理论之是否真理…而是依客观上社会实践的结果如何而定"｜「南方谈话」"不是靠本本，而是靠实践，靠实事求是"
2. **矛盾分析**——一切事物内部都有矛盾，抓主要的那个｜《矛盾论》"就要用全力找出它的主要矛盾。捉住了这个主要矛盾，一切问题就迎刃而解了"
3. **实践是循环而非一次性验证**——计划被推翻是常态｜《实践论》"原定的思想、理论、计划、方案，部分地或全部地不合于实际…都是有的"
4. **群众是力量来源、信息渠道、检验标准**｜《关于领导方法的若干问题》"从群众中来，到群众中去"｜「各项工作都要有助于…」"是否有助于人民的富裕幸福，是否有助于国家的兴旺发达"

### 推导出的四条决策逻辑
- 由①推出：**结论必须在调查之后**｜《反对本本主义》"一切结论产生于调查情况的末尾，而不是在它的先头"
- 由②推出：**一个时期只能有一个中心**｜《关于领导方法的若干问题》"在一定时间内只能有一个中心工作"｜「目前的形势和任务」"其他一切任务都要服从这个中心…决不能干扰它，冲击它"
- 由③推出：**改计划不是事故**｜《中国革命战争的战略问题》"如果计划和情况不符合…把已定计划加以改变，使之适合于新的情况"
- 由④推出：**判据必须能被群众的结果检验**｜《延安文艺座谈会上的讲话》"社会实践及其效果是检验主观愿望或动机的标准"｜「南方谈话」"三个有利于"

## 三、七步决策法（主流程，照做即可）

```
0 定性  →  1 摸底  →  2 拆矛盾  →  3 立中心  →  4 备判据比力量
                                                        ↓
                              7 复盘纠偏  ←  6 执行推广  ←  5 定策略
```

**第 0 步｜先问"这是什么性质的事"**
性质不清不谈对策。分清是"分清敌我"还是"分清是非"｜《关于正确处理人民内部矛盾的问题》"前者是分清敌我的问题，后者是分清是非的问题"
→ 输出一句话：**这件事本质上是什么。**

**第 1 步｜占有材料，反对三样东西**
亲身到场、开调查会、追问数量｜《反对本本主义》"不能单靠书面报告，因为二者是两回事"｜《党委会的工作方法》"任何质量都表现为一定的数量，没有数量也就没有质量"
忌带三性——主观性、片面性、表面性｜《矛盾论》"研究问题，忌带主观性、片面性和表面性"
→ 输出：**事实清单 + 数字**。数字拿不到，就明确写"此处无数据"。

**第 2 步｜拆矛盾，抓主要的那个**
列出全部矛盾 → 找出主要矛盾 → 分主要方面/次要方面 → 判断会不会转化｜《矛盾论》"不能把过程中所有的矛盾平均看待"
**不同质的矛盾只能用不同质的方法**｜《矛盾论》"不同质的矛盾，只有用不同质的方法才能解决"
→ 输出：**主要矛盾一句话 + 次要矛盾清单**。

**第 3 步｜收敛到一个中心任务**
中心唯一，其余排队服从｜「目前的形势和任务」"其他一切任务都要服从这个中心"
一个时期主要方向只有一个｜《中国革命战争的战略问题》"在一个时间内，主要的使用方向只应有一个"
→ 输出：**中心任务 + 明确的"不做什么"清单**（这一条最容易被跳过，也最容易出错）。

**第 4 步｜先立判据，再比力量**
在下判断**之前**先写下判据，防止事后找理由。
- 邓式判据三问：**是否有利于…的生产力 / 综合国力 / 生活水平**（换成你的场景：客户价值 / 组织能力 / 团队收益）
- 毛式力量对比：**至少四个维度同时比**——强弱、大小、进步退步、多助寡助｜《论持久战》"亡国论者看重了强弱一个矛盾，把它夸大起来作为全部问题的论据，而忽略了其他的矛盾"
→ 输出：**判据表 + 力量对照表**。

**第 5 步｜按情境选策略**（见第六节模式库）
核心动作有四类：**决战 / 撤退 / 试点 / 观望**，分别对应不同把握度。

**第 6 步｜先试点，后推广**
没有个别经验，不作普遍指导｜《关于领导方法的若干问题》"突破一点，取得经验，然后利用这种经验去指导其他单位"
邓：允许看，但要坚决地试｜「南方谈话」"允许看，比强制好得多"｜"证券、股市…允许看，但要坚决地试"
毛式本土配置：几定制度｜「解放思想，实事求是…」"定任务、定人员、定数量、定质量、定时间"
→ 输出：**试点范围 + 失败退出路径 + 责任人 + 时间表**。

**第 7 步｜固定周期复盘，错的赶快改**
邓：走一段就总结，哪一步不妥当就赶快改｜「改革是中国的第二次革命」"重要的是走一段就要总结经验…哪一步走得不妥当，就赶快改"
毛：不是追责，是流程｜《中国革命战争的战略问题》"部分地改变的事差不多每一作战都是有的"
关键纪律：**纠错不得伤及大政方针的稳定性**｜「革命和建设都要走自己的路」"第一不能犯大错误，第二发现不对就赶快改"

## 四、论据工具箱（用什么东西说服自己和别人）

按强度排序，越靠前越有说服力：

| # | 论据类型 | 用法 | 原句 |
|---|---|---|---|
| 1 | **已发生的事实/实践结果** | 最优先，可一票否决理论推演 | 「南方谈话」"深圳的建设成就，明确回答了那些有这样那样担心的人" |
| 2 | **一手调查材料** | 高于书面报告 | 《反对本本主义》"一定都要亲身从事社会经济的实际调查" |
| 3 | **量化数据** | 没有数量就没有质量 | 《党委会的工作方法》"没有数量也就没有质量" |
| 4 | **多维度力量对照** | 禁止单点归约 | 《论持久战》"忽略了其他的矛盾" |
| 5 | **可度量判据** | 把抽象争论换成三条标准 | 「南方谈话」三个有利于 |
| 6 | **试点经验** | 局部验证胜过全局论证 | 「党和国家领导制度的改革」"成熟一个，解决一个" |
| 7 | **国际/外部比较** | 校准位置和阶段 | 「谈话要点」"日本、南朝鲜、东南亚一些国家和地区，就是如此" |
| 8 | **自己的失败教训** | 分量最重的论据之一 | 「党和国家领导制度的改革」"斯大林严重破坏社会主义法制"｜《学习和时局》"对于任何问题应取分析态度，不要否定一切" |
| 9 | **历史类比** | 辅助，不可单独使用 | 《论持久战》引中外战史 |
| 10 | **条件式推论** | 写成"如果…则…"，不做断言 | 《星星之火，可以燎原》"只应该也只能说出个大的方向，不应该也不可能机械地规定时日" |

**反面清单**（这些不算论据）：主观想象、一时热情、死的书本、未经核实的书面报告、只对局部事实的夸大。

## 五、必查变量清单（决策前逐个打勾）

**通用层**
- [ ] **性质**：这是哪类矛盾？会不会转化？
- [ ] **主要矛盾**：现在到底哪一个起决定作用？上一次判断是什么时候做的？
- [ ] **力量对比**：至少比四个维度，不许只比强弱
- [ ] **时间/阶段**：处在哪个阶段？该阶段的形式与前一段是否不同？
- [ ] **人心 / 群众接受度**：超前是冒险主义，落后是尾巴主义｜《论联合政府》"命令主义是错误的，因为它超过群众的觉悟程度"
- [ ] **信息与确定性**：承认"更少确实性"，但找"朕兆可寻、端倪可察"｜《论持久战》

**毛线补充变量**：同盟者可靠性（中间派必然分化）、地形与条件、双方士气、内部团结是否破裂、经济财政承受力、骨干队伍、国际力量对比、敌方执行情况
**邓线补充变量**：政策稳定性（"不要使人们感到政策变了"）、干部与接班人（"关键在人"）、速度与物价、时机窗口、中央权威与执行统一、人才使用、农业与基本盘

## 六、不确定性环境的决策模式库（核心）

这是这套技能最有价值的部分。**先识别情境，再套动作。**

### 情境 A｜信息不足，但不必马上决定
**动作：调查，不争论。**
- 亲自到场、开调查会、《反对本本主义》"把你所谓困难问题的“来源”找到手，“现状”弄明白"
- 禁止用账面上的乐观替代一手材料

### 情境 B｜信息不足，却必须现在拍板
**动作：承认不完备，追求"一般地正确的指导"。**
- 毛式：侦察 + 聪明推论 + 给计划"相对的固定性"｜《论持久战》"先之以各种侦察手段，继之以指挥员的聪明的推论和判断，减少错误，实现一般的正确指导，是做得到的"
- 只要"在有决定意义的部分适合情况"即为胜利基础｜《中国革命战争的战略问题》
- 邓式：**允许看、坚决试、不争论**｜「南方谈话」"允许看，比强制好得多"｜"不争论，是为了争取时间干"
- **不要假装能算准**：允许只说方向不说时日｜《星星之火，可以燎原》"马克思主义者不是算命先生，未来的发展和变化，只应该也只能说出个大的方向，不应该也不可能机械地规定时日"

### 情境 C｜力量悬殊，对手明显强
**动作：战略上藐视、战术上重视；局部优势累积成全局优势。**
- 《中国革命战争的战略问题》"我们的战略是“以一当十”，我们的战术是“以十当一”"
- 集中优势兵力打一点｜《集中优势兵力，各个歼灭敌人》"至少也要有三倍于敌的兵力"
- 打不赢就走｜《论持久战》"这是以土地换时间的正确的政策"
- **绝不赌全局**：《论持久战》"赌国家命运的战略决战应根本避免"

### 情境 D｜局面突变 / 外部冲击
**动作：先稳住，不急变。**
- 邓式四步：**冷静观察 → 稳住阵脚 → 沉着应付 → 埋头干好自己的事**｜「改革开放政策稳定，中国大有希望」
- 毛式配套：**重估主要矛盾是否变了**｜《关于打退第二次反共高潮的总结》民族矛盾仍是基本的
- 关键纪律：「改革开放政策稳定，中国大有希望」"唯一的办法是我们自己不乱"

### 情境 E｜看不清对错、内部有分歧
**动作：把争论换成判据，用试点替代说服。**
- 邓：不争论是为抢时间｜"一争论就复杂了，把时间都争掉了，什么也干不成"
- 但要防止把"不争论"变成拖延——所以必须**同时设定试点退出条件**：「南方谈话」"看对了，搞一两年对了，放开；错了，纠正，关了就是了。关，也可以快关，也可以慢关，也可以留一点尾巴"

### 情境 F｜时机窗口出现
**动作：果断抓住，同时留治理余地。**
- 「谈话要点」"我就担心丧失机会。不抓呀，看到的机会就丢掉了"
- 「总结经验，使用人才」"强调稳是对的，但强调得过分就可能丧失时机"
- 动作组合：**抓住时机加速几年 → 发现问题及时治理 → 尔后继续前进**｜「南方谈话」

### 情境 G｜已经出错了
**动作：局部化 + 短周期 + 不大改。**
- 允许失败多次：《实践论》"许多时候须反复失败过多次，才能纠正错误的认识，才能到达于和客观过程的规律性相符合"
- 邓｜「南方谈话」"每年领导层都要总结经验，对的就坚持，不对的赶快改，新问题出来抓紧解决"
- 毛｜同时反"左"和反右：《实践论》"反对一切离开具体历史的“左”的或右的错误思想"——**认识落后要反右，认识超前要反"左"**

## 七、领域决策矩阵

每个领域给出：**判据 → 关键动作 → 双源对照**。详细结构与原句见 references。

### 经济
- **判据**：是否发展了生产力/国力/人民生活｜「南方谈话」三个有利于；「各项工作都要有助于…」
- **财政与经济的主从**：经济决定财政而非相反｜《抗日时期的经济问题和财政问题》"决定财政的却是经济"
- **动作**：局部试验再推开｜「解放思想…」"可以先从局部做起，从一个地区、一个行业做起"
- **节奏**：积极、留有余地、经过努力才能达到｜「各项工作都要有助于…」
- **底线**：农业/基本盘不能被牺牲｜「各项工作都要有助于…」"农业是根本，不要忘掉"
- **时机**：抓住时机加速几年，出问题再治理｜「南方谈话」
- **毛的补充**：目标与手段可反向——想多重工业先投农业轻工业｜《论十大关系》；两个积极性比一个好｜《论十大关系》"有中央和地方两个积极性，比只有一个积极性好得多"

### 外交
- **判据**：主权安全第一位｜「国家的主权和安全要始终放在第一位」
- **格局判断**：先看国际大格局（和平与发展两大问题）｜「和平和发展是当代世界的两大问题」
- **姿态**：**决不当头**｜「善于利用时机解决发展问题」"千万不要当头，这是一个根本国策…许多主动都失掉了"
- **三句固定口径**：反对霸权主义、维护世界和平、加强同第三世界团结合作｜「中国的对外政策」
- **不被制裁吓住**：「中国永远不允许别国干涉内政」"我们并不着急，也不悲观，泰然处之"
- **毛的补充**：利用矛盾、争取多数、反对少数、各个击破｜《论政策》；**在不同区别上建立不同政策**；自力更生为主、外援为辅｜《论政策》；本质上是纸老虎、具体上是真老虎｜《和美国记者安娜·路易斯·斯特朗的谈话》

### 社会治理
- **判据**：稳定是硬约束、是前提｜「压倒一切的是稳定」"没有稳定的环境，什么都搞不成，已经取得的成果也会失掉"
- **排序规则**：「目前的形势和任务」"一定要在不妨碍安定团结的条件下实现生动活泼"
- **手段演进**：从集中打击过渡到立法与常态化｜「中国不允许乱」"特别要抓紧立法"
- **毛的配套**：先分两类矛盾再选工具｜《关于正确处理人民内部矛盾的问题》；公式是"团结—批评—团结"；两条群众原则——**实际需要 + 自愿**，缺一即失败｜《文化工作中的统一战线》
- **分寸**：一张一弛｜《对晋绥日报编辑人员的谈话》"把弓弦拉得太紧了。拉得太紧，弓弦就会断"

### 治党
- **判据**：制度比个人作风更根本｜「党和国家领导制度的改革」"领导制度、组织制度问题更带有根本性、全局性、稳定性和长期性"
- **三路监督**：党的监督、群众监督、民主党派与无党派监督｜「共产党要接受监督」
- **用小民主避免大民主**｜「共产党要接受监督」"如果没有小民主，那就一定要来大民主"
- **取消运动式治理**：「党和国家领导制度的改革」"用大搞群众运动的办法，而不是用透彻说理、从容讨论的办法…从来都是不成功的"
- **选人**：关键在人｜「总结经验，使用人才」；德才兼备、四化｜「党和国家领导制度的改革」
- **毛的配套**：三大作风｜《论联合政府》；集体领导与个人负责不可偏废｜《关于健全党委制》；批评的目的是救人不是整人｜《整顿党的作风》"完全是为了救人，而不是为了把人整死"；力戒骄傲｜《党委会的工作方法》

### 军事 / 竞争
- **目的**：保存自己、消灭敌人；一切形式按效果取舍
- **交战原则**：集中绝对优势兵力、以歼灭有生力量为目标、有把握才决战｜《集中优势兵力，各个歼灭敌人》"以歼灭敌军有生力量为主要目标，不以保守或夺取地方为主要目标"
- **全局观**：指挥员注意力放在对全局有决定意义的关节上｜《中国革命战争的战略问题》
- **军队服从大局**：「军队要服从整个国家建设大局」"现在需要的是全国党政军民一心一意地服从国家建设这个大局"

### 科技 / 教育 / 人才
- **判据**：科技是第一生产力｜「科学技术是第一生产力」
- **愿意牺牲速度保教育**｜「科学技术是第一生产力」"在别的方面忍耐一些，甚至于牺牲一点速度，把教育问题解决好"
- **人才果断起用、容忍缺点**｜「总结经验，使用人才」"即使有某些弱点缺点，也要放手用"
- **毛的配套**：没有文化的军队是愚蠢的军队｜《文化工作中的统一战线》

### 组织间的对立与结盟（统一战线）
- **三环节**：发展进步势力、争取中间势力、反对顽固势力｜《目前抗日统一战线中的策略问题》
- **以斗争求团结**｜"以斗争求团结则团结存，以退让求团结则团结亡"
- **斗争三原则**：有理、有利、有节，三者缺一就要吃亏｜《关于打退第二次反共高潮的总结》
- **争取中间派的三个条件**：我有充足力量、尊重其利益、对顽固派斗争能逐步取胜

## 八、执行清单（会前对照，逐条打勾）

1. 这件事的**性质**写清楚了吗？（是分清敌我，还是分清是非？）
2. 事实部分有没有**数字**？数字是从现场来的还是从报告里抄的？
3. **主要矛盾**是不是唯一？最近一次重估是什么时候？
4. **中心任务**是不是只有一个？"不做什么"的清单列了吗？
5. **判据**是不是在**判断之前**就写好了？（事后找理由 = 无效）
6. 力量的对比**至少比了四个维度**吗？有没有只比强弱？
7. 属于七种情境（A–G）中的哪一种？套了对应动作吗？
8. **试点范围**可控吗？失败时的**退出路径**想清楚了吗？
9. 这个决定会不会被误读成"风向变了"？（邓式政策稳定检验）
10. **执行人**是谁？责任是否"几定"（定任务、定人员、定数量、定质量、定时间）？

**收口四句话**（背下来就够用一半）：
- "没有调查，没有发言权"——《反对本本主义》
- "用全力找出它的主要矛盾"——《矛盾论》
- "具体地分析具体的情况"——《矛盾论》
- "胆子要大，步子要稳，走一步，看一步"——「改革是中国的第二次革命」

## 九、使用纪律

1. **引用必带篇名**。给结论时按「篇名」+ 原句的格式给出，不确定的句子不要写。
2. **两人不一致时不要和稀泥**。毛偏"对抗与转折"，邓偏"稳定与节奏"，明确说明当前该用哪一套，或说明两者各管哪一段。
3. **不要做政治评价**。这套技能提取的是**决策方法论**（怎么调查、怎么分析、怎么试错、怎么纠偏），不是对人物或历史事件做价值判断。
4. **判据前置**。任何一次决策推演，先把判据写在前面，再看结论。
